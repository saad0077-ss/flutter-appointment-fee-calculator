# Flutter Appointment Fee Calculator

A beginner-friendly Dart project developed to understand and practise Unit Testing using Flutter's testing framework.

## Features
- Calculate consultation fees.
- Calculate additional service charges.
- Support multiple services.
- Simple and reusable business logic.

## Calculation Formula

Total Fee = Consultation Fee + (Service Fee × Number of Services)

## Example

- Consultation Fee: ₹500
- Service Fee: ₹100
- Number of Services: 2
- Total Fee: ₹700

## Testing

This project demonstrates:
- Unit Testing
- Test Groups
- Assertions using `expect()`
- Positive Testing
- Negative Testing
- Edge-case Testing
- Arrange – Act – Assert pattern

## Run Tests

```bash
flutter test
```

## Technologies
- Dart
- Flutter
- flutter_test

## Learning Objective

To understand how to write reliable, maintainable, and automated unit tests for Flutter application business logic.
